1. CREATE DIRECTORIES
   mkdir -p barter-app/{backend,frontend}/src

2. COPY BACKEND FILES
   Copy 10 BACKEND_*.txt files to backend/src/

3. COPY FRONTEND FILES
   Copy 6 FRONTEND_*.txt files to frontend/src/

4. INSTALL BACKEND
   cd backend && npm init -y && npm install

5. INSTALL FRONTEND
   cd frontend && npx create-expo-app . && npm install

6. START BACKEND
   cd backend && npm run dev

7. START FRONTEND
   cd frontend && npm start

AUTH

USERS (Auth Required: Bearer TOKEN)
  GET    /api/users                 Current user profile
  GET    /api/users/:userId         Any user profile
  PUT    /api/users                 { firstName, lastName, bio, ... }

ITEMS
  GET    /api/items                 ?category=X&condition=Y&search=Z
  GET    /api/items/nearby          ?latitude=X&longitude=Y&maxDistance=50000
  GET    /api/items/:itemId         
  POST   /api/items                 { title, description, category, condition, ... }
  PUT    /api/items/:itemId         { title, description, condition, available }
  DELETE /api/items/:itemId         

TRADES (Auth Required)
  POST   /api/trades                { proposerItemId, receiverId, receiverItemId, message }
  GET    /api/trades                ?status=proposed
  GET    /api/trades/:tradeId       
  PUT    /api/trades/:tradeId/accept
  PUT    /api/trades/:tradeId/complete   { rating (1-5), review }
  PUT    /api/trades/:tradeId/decline

🔐 AUTHENTICATION FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. User registers                    POST /auth/register
2. Backend hashes password           bcrypt (10 rounds)
3. User logs in                      POST /auth/login
4. Backend returns JWT token         7-day expiry
5. Frontend stores token             AsyncStorage
6. Frontend includes token           Bearer <token> header
7. Backend validates on each request Auth middleware

JWT Payload:
  { userId: "507f1f77bcf86cd799439011" }

Find nearby items:
  GET /api/items/nearby?latitude=40.7128&longitude=-74.0060&maxDistance=50000

MongoDB geospatial query:
  {
    location: {
      $near: {
        $geometry: { type: "Point", coordinates: [longitude, latitude] },
        $maxDistance: 50000 // meters
      }
    }
  }

Distance calculation in km:
  distance_meters / 1000 = distance_km

⭐ RATING SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Trade accepted by both parties
2. Both mark trade as complete
3. Both submit rating (1-5 stars) & review
4. Ratings calculated:
   newRating = (oldRating × oldCount + newRating) / (oldCount + 1)
5. User stats updated
6. Badges checked (infrastructure ready)

User.rating field updated after each trade completion
